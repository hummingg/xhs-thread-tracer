# 隐私政策（Privacy Policy）

**最后更新：2026-10-24**

小红书对话链增强（XHS Thread Tracer）是一款浏览器扩展，用于改善小红书网页版评论区的阅读体验。我们高度重视隐私，政策如下：

## 我们收集什么数据

**不收集任何数据。** 本扩展：

- 不收集、不存储、不上传任何个人身份信息
- 不包含任何分析、追踪或广告代码
- 不向任何服务器发起网络请求（`permissions` 为空数组，无 host 权限）

## 数据如何处理

扩展仅在本浏览器内**本地、临时**地处理两类信息：

1. **页面自身的评论接口响应**：扩展在页面内旁听小红书网页版自己发出的评论 API 响应（只读），用于在本地还原评论的回复关系，生成对话树展示。这些数据不离开你的浏览器，关闭页面即消失。
2. **页面 DOM 内容**：读取评论区的昵称、正文、图片等元素，用于注入按钮与面板展示。同样仅存在于当前页面内存中。

扩展不使用 `chrome.storage`、不使用 Cookie、不读取浏览历史。

## 权限说明

本扩展未申请任何权限（`"permissions": []`），仅通过内容脚本匹配 `https://www.xiaohongshu.com/*` 运行。

## 联系方式

如有疑问请在本项目仓库提交 Issue：https://github.com/hummingg/xhs-thread-tracer/issues

## 免责声明

本扩展为个人学习性质的开源项目，与小红书官方无关。使用时请遵守小红书用户协议与相关法律法规，不用于批量数据采集。
